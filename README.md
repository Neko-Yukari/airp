# AIRP

AIRP 是一个以持续场景、独立人物上下文和多 Agent 协作为核心的角色扮演世界模拟器原型。

当前版本实现了最小人物层闭环：

```text
玩家 → 场景管理者 → 人物实体 → 场景管理者 → 玩家
```

## 当前能力

- 费伦背景下的灰栎村单场景原型
- DeepSeek 驱动的管理者路由、人物回应与最终场景续写
- 每个人物独立的 Scene 会话上下文
- 管理者完整 Scene 记录
- 玩家可编辑的管理者叙事偏好
- 基础物品生成与查看
- JSON 结构校验、失败重试和自动测试

多人物调度、离场结算、长期记忆、关系演化和数据库审计仍属于后续阶段。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

复制 `.env.example` 为 `.env.local`，并填入测试用的 DeepSeek API 密钥。不要把真实密钥提交到 Git。

## 验证

```bash
npm run build
node --test tests/*.test.mjs
```
